Outil de correction CSV/eCSV (ITACA)
Description

Pipeline multi-agents IA déployé sur AWS pour automatiser la validation et la correction de fichiers CSV médicaux dans un contexte international (3 hôpitaux, 3 pays). 8 agents orchestrés par AWS Step Functions — algorithmes déterministes pour les cas simples, embeddings ML.NET pour la sémantique — sans aucun appel API externe. Résultats : +93% de correction automatique, −74% de temps de traitement.

Projet DevOps
Description

Projet DevOps complet mettant en place un workflow CI/CD (lint, tests Jest, build, push, déploiement) pour une application de gestion de listes/tâches, conteneurisée avec Docker et déployée automatiquement sur Kubernetes (k3d/Kind). La persistance est assurée par MariaDB avec volume, et les secrets (credentials) sont gérés via des variables GitLab CI injectées dans les pods, avec possibilité d’ajouter monitoring (Prometheus/Grafana) et tests E2E (Cypress).

Deep Learning - CNN
Description

Projet de Deep Learning centré sur la conception et l’entraînement de réseaux de neurones convolutionnels (CNN) avec TensorFlow et Keras pour la classification d’images.

Le projet couvre plusieurs problématiques clés du Deep Learning : classification MNIST et CIFAR-10, création d’architectures convolutionnelles, visualisation des filtres, augmentation de données, régularisation des gradients et utilisation du modèle pré-entraîné VGG16.

Une architecture CNN optimisée a permis d’atteindre près de 99 % de précision sur MNIST grâce à l’utilisation de couches convolutionnelles, MaxPooling, Dropout et techniques d’augmentation de données.

Technologies
Python TensorFlow Keras CNN Deep Learning VGG16 MNIST CIFAR-10
Résultats
  • Conception et entraînement de plusieurs architectures CNN.
  • Classification d’images manuscrites et naturelles.
  • Visualisation des filtres convolutionnels et feature maps.
  • Mise en œuvre de techniques d’augmentation de données et de régularisation.
  • Obtention d’une précision proche de 99 % sur le dataset MNIST.
